# Fovea Studio 宣传文案规范

适用范围：官网和落地页、SEO（标题、描述、关键词）、分享卡片（OG/Twitter）、YouTube @FoveaSI、Product Hunt、社交媒体帖子、邮件和广告文案。

## 一、定位

Fovea 是一个工具：你提供歌曲和歌词，它帮你生成歌词视频。

- **核心说法**：你的歌曲 + 你的歌词，生成歌词视频。
- **卖点**：排版好看、多种版式（竖屏滚动、卡拉 OK、动态海报）、上手快、可以免费试用。

## 二、禁止内容

1. **不提 Suno**，也不提任何第三方品牌或商标（包括 Udio 等其他音乐生成平台）。不出现在文案、页面标题、关键词、URL、路由、图片说明（alt）、话题标签里。
2. **不做“给 Suno 用户”之类的落地页**、对比页或引流关键词。
3. **不暗示我们和这些品牌有合作或背书关系**。
4. **不提 AI**。不使用“AI 生成”、“AI 音乐”、“AI 歌曲”、“AI 驱动”、“智能生成”这类说法（英文的 AI-generated、AI music、AI-powered 也一样）。
5. **不把产品定位成 AI 音乐工具的配套**。
6. **不使用别人的歌曲、歌手名或专辑封面做宣传**，除非拿到了授权。

## 三、推荐用词

| 不要这样写 | 可以这样写 |
| :--- | :--- |
| 把你的 Suno 歌曲做成 MV | 把你的歌曲做成歌词视频 |
| 为 AI 音乐打造 | 为你的歌曲和歌词打造 |
| AI 驱动的歌词视频 | 几分钟做好歌词视频 / 制作歌词视频 |
| AI-generated songs | your song / your track and lyrics |
| AI lyric alignment | Automatic lyric alignment / 自动对齐 |

## 四、发布前检查

1. 全文搜索 `suno`（不区分大小写），结果为 0。
2. 全文搜索 `AI`、`人工智能`、`智能生成`，结果为 0（隐私协议中的技术必要披露除外）。
3. 页面标题、meta 描述、关键词、分享卡片和图片说明都检查过。
4. 官网改动在 staging 预览通过后再合并到 main。
5. 代码里的自动检查（CI 测试：`frontend/tests/no-suno-marketing.test.cjs`）已通过。

## 五、修改流程

1. 官网文案只改生成脚本（`scripts/build_marketing.py` 和它用到的模板、数据），不要手改生成出来的 HTML。
2. 先在 staging 分支修改，开 PR，预览通过后再合并。
