# 页面地址

页面统一使用小写英文与连字符，一项功能一个入口：

| 页面 | 地址 |
| --- | --- |
| 首页与任务列表 | `/` |
| 歌词编辑 | `/lyric-editor` |
| 编辑指定任务 | `/lyric-editor/{task_id}` |
| 动效导演 | `/motion-studio` |
| 作品库 | `/gallery` |
| 分镜 | `/storyboard` |
| 动效实验页 | `/motion-lab` |

旧的 `/local/...`、`/editor`、`/lyric_editor`、`/motion_studio`、
`/motion_studio_director` 和 `/motion` 不再作为页面入口，不保留兼容跳转。
未知地址显示 404，用户可以从首页重新进入。

Cloudflare Pages 直接通过根目录同名 HTML 文件提供页面；不要把干净路径
重写到 `.html`。Pages 会自动把 HTML 地址规范化为无扩展名地址，二者组合
会产生指向自身的 308 重定向循环。

部署脚本把根目录页面链接复制成实际文件，排除内部 `local/*.html`，保留
`/static/*`、`/motion/*` 和样式资源。`/lyric-editor/*` 只重写到无扩展名的
`/lyric-editor`。构建阶段拒绝可能产生循环的 HTML 重写规则。

页面地址变化不影响 `/api/...` 接口、数据库记录、音频或已保存的任务。

## 云端动效数据

Pages 只提供静态页面。Motion Studio 在云端使用 Firebase 登录凭据请求
后端 `/api/cloud-motion/...`；本地继续使用 `/api/motion/...`。
云端歌曲 ID 是当前用户的任务 ID，不是服务器文件路径；音频使用同一
任务的受保护音频接口。返回 HTML 或登录失效时，页面显示明确的错误提示。

导演方案、歌曲信息、封面和导出文件保存在当前 StorageBackend 的
`motion/{用户命名空间}/{task_id}/` 下，用户命名空间由服务端身份生成。
服务重启后从该目录恢复；删除任务时一起清理。云端导出保持私有，不能
通过原本面向本地个人工具的公开作品同步接口自动发布。

Suno 导入同时在任务的输入目录保存 `source_suno.json`（仅歌曲 ID、歌名、
创作者和来源图片地址）与经过校验的 `source_cover.jpg`。它们通过同一私有
存储恢复到 Motion Studio，不依赖容器目录或外部 CDN 持续可用。
旧任务可使用“刷新 Suno 歌曲信息”补取；不派发对齐任务、不扣额度，已有
自定义署名、封面和歌词保持原样。删除任务时一并清理这两项源资料。

竖屏排版使用整组文字的重心与阅读安全区，缩小主次字号差距，并在节点
内部平衡折行；不更改语义分块或演唱时间。长署名在播放页省略显示，片头
保留完整标题。片头和片尾使用已有前奏、尾奏，不新增歌曲时长。

来源图片同时保留 Suno URL 和优化后的私有缓存（JPEG、最长边不超过
1600px）。缓存是可靠性保障，不替代来源信息；用户上传的图片是独立的
自定义资产。元数据中的图片内容指纹用于版本检查：普通打开工程复用
本地缓存，图片变化或本地副本丢失时才从存储恢复；主动刷新仍会检查
Suno 来源，内容相同则不重复上传，读取失败保留已有图片。
