# Motion Studio：歌词 → 动效导演 → MP4

入口 `/motion_studio` 与歌词编辑器共用 Python 服务、歌曲目录和原曲 API。`/motion_lab` 保留模板实验预览，成片制作进入 Studio。旧实验服务及 MFA 分支未改动。

## 用户流程

1. 导入歌曲并完成 alignment / 音频分析，或选已有工程。
2. 在 Studio 选择横竖屏与色调，生成规则导演方案。
3. 可下载 LLM 提示词，将它交给用户选择的 LLM，再粘贴返回 JSON。当前没有自动调用外部模型或使用账号密钥。
4. 校验通过后应用方案。逐句选择动画、左右布局、色调、强度和强调词；锁定句在再次导演时保留；支持单句重新导演。
5. 保存方案，导出整曲或指定片段 MP4。预览与导出共用 `MotionEngine.renderAt`，输出 30fps H.264/AAC。导出采用保存方案与参数的快照，期间修改不会改变正在导出的影片。

窗口沿用 Motion Lab 的大预览与设置侧栏。小屏保留真实画幅比例，设置移动到下方；“放大预览”隐藏设置区。

## 契约与模板

导演输入 `motion-input-v1` 包含稳定句 ID、原词级时间、乐段、句级平均能量、附近拍点、模板说明及输出 JSON Schema。不会发送完整的 100Hz 曲线或原曲本地路径。

导演输出 `motion-plan-v1` 保存于歌曲旁的 `<song>_motion_plan.json`，含源歌词指纹、固定随机种子及逐句参数。完整覆盖有效歌词；零时长标注不作为动画句；模板、参数范围、强调词及锁定条目均校验。对齐变更会使旧方案失效，需重新生成。

当前模板：`word-impact` 字词击打、`phrase-rise` 整句上浮、`quiet-hold` 静置淡入淡出。布局 center/left，荧绿/冷蓝两套配色。按字体测量缩放换行，强调词支持原文子串；句间用歌曲标题和音乐背景留白。此版尚无独立跨句转场、三维文字空间模板或原版 pdoom 的自适应运动模糊。

无拍点时关闭节拍冲击，不默认伪造 120 BPM。鼓类别和重拍的估计限制沿用音频分析数据。

## 运行与部署

前端目录 `frontend/motion`：Node 22，`npm ci`，`npm run check`，`npm test`，`npm run build`。

构建后启动正常 Python 编辑器即可；也可设 `M2V_PYTHON` 后运行 `npm run dev`（默认 8768）。渲染环境需 Node、FFmpeg 和 Chrome/Chromium；`CHROME_PATH` 可指定浏览器。默认 macOS Chrome 或 Linux `/usr/bin/chromium`。720p 为默认，360p 为快速验证模式。

CI 已加入前端检查/构建与真实 2 秒 Chrome/FFmpeg 成片测试。Dockerfile 增加 Node 构建阶段、渲染依赖与 Chromium。此工作环境无 Docker，未验证镜像构建或云端部署。字体使用系统中文字体，本机预览和导出共用字体；不同平台的系统字体可能造成排版差异，跨平台固定字体仍需后续补充。

导出限同时一个任务，提供进度、取消与错误提示；成片、方案快照和完成记录位于歌曲 `motion_exports/`。完成记录和下载在服务重启后保留；运行中的任务不会自动恢复。当前不提供批量队列。

## 本地验证

《04tuZiDongV1》29 句、3 种模板，整曲 198.8 秒 / 5,964 帧 / 640×360，H.264 与 AAC 音轨已验证。整曲测试为 360p、关闭后处理；含后处理的 2 秒片段也已验证。未宣称完整歌曲 720p 的性能或远端 LLM 创作质量已验证。

## 单句导演流程升级

详见 `motion-director-api.md`：单句提示词包含目标字词索引、音乐摘要、相邻句和已有方案；LLM 返回 groups，系统从 alignment 计算时间。页面提供“下载当前句提示词”、单句/整曲范围、“仅校验”、“应用并保存”，避免校验阶段修改工程。

单句引用源歌词指纹和目标句方案指纹：对齐变化拒绝旧返回，目标句被修改/锁定时返回冲突，其他句子的最新修改保留。返回的词组在当前平面渲染器中执行揭示、突出、回位、停留；整句字幕持续保留。空间草案仍不等同于真正的三维文字模板。

## 二维静态海报样例

Studio 顶栏“例句海报”打开横屏 1280×720 的最终排版预览，可下载 PNG 或设计 JSON。“欢迎来到”是引导，“我的”作为小字归属，“兔子洞”是最大标题，“这里没有”和“所谓的成功”在下方构成转折与收尾。背景使用浅纸色和扁平圆环意象。

`motion-poster-v1` 为独立静态设计样例，尚未接入 LLM 返回方案或 MP4 动画。各文字对象含原句 `word_indices`、归一化位置/宽高、字号（相对画布高度）、字重、颜色。绘制使用实际字体测量并缩小到预留框内；当前版限定横屏。设计数据见 `examples/rabbit-hole-poster.json`，渲染模块为 `frontend/motion/src/poster.ts`。后续入场动画可以直接使用这些最终位置和字词引用。

整曲/单句 LLM 提示词已升级为“语义海报设计 → 几何编译 → 时间绑定 → 渲染”。当前实现的是第一层数据合同与校验。LLM 只选排版 archetype、文字层级、强调与动作意图；不写坐标、字号或绝对时间。具体字段及当前执行边界见 `motion-director-api.md`。
