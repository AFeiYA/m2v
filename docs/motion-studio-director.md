# Motion Studio：歌词海报到动画

当前分支 `codex/motion-studio-director` 采用 Python 音频与导演接口 + React/Remotion 帧渲染。

## 用户流程

1. 选择已有 alignment 歌曲工程，选择横屏/竖屏及分辨率。
2. 读取保存的导演方案或自动生成基础方案。没有海报设计的旧句子使用基础海报排版，不需要覆盖旧工程即可预览。
3. 下载整曲/单句 LLM 提示词，粘贴返回 JSON，先校验再应用。当前仍由用户选择外部 LLM，没有自动发送歌词或账号密钥。
4. 选择句子，点击顶栏“当前句海报”查看最终静态排版，下载 PNG 或编译后的 JSON。
5. 逐句调整区可查看引导、对照、否定、重复和空间意象关系；自动模式让关系参与已有排版与动作选择；可切换为手工参数，并查看实际编排结果。
6. “播放当前句动画”按演唱锚点逐块进入，落位后保留，结束后停留在完整海报供复核；整曲播放根据下一句起点执行交接；“播放本句与交接”可试听本句到下一句入场。
7. 调整海报模板、节点主次、入场、驻留及主视觉拍点回弹，保存后导出片段或完整 MP4。

## 同一份排版和时间

`poster-layout.ts` 根据实际字体度量，计算安全区、槽位、换行与字号。提供主标题层级、居中层叠、左右错落三种规则，支持 16:9 / 9:16。文字块以实际字形高度紧凑堆叠，行距 1.04，主标题尽量固定在中央基线，辅文不超过主标题字号的 55%；短句可扩大主标题，密集快唱压低整体范围与动作。横竖屏均保留安全区，不做破画裁切。已有 Verse/Chorus 标签参与排版高度上限，但没有标签时不推测段落。

Studio 全曲使用 visual_language 的背景/强调色，缺省继承第一张海报；环境符号继承第一张海报，不随每句刷新。句间空隙先保留完整海报供阅读，再按 fade/cut 交接；长间奏在有限文字余韵后保留背景，不再闪回歌曲标题。重复歌词在分块相同时继承初次版式与角色；锁定句保留原版式。编译不改写保存的源方案。当前仍一句一个时间单元，可排成两行；没有两句同时驻留、方向性出场、段落舞台换色或自动 tracking。

`lyric-video.tsx` 是预览与导出的共同 Remotion 组件。文字通过 SVG 按编译基线绘制，动画完全由帧号及 alignment 锚点求值，不使用 CSS transition/animation。静态 PNG 使用相同几何结果。音频是实时预览的主时钟，跳转完成后同步 Player 的帧号。

整句 cumulative 拼成海报，入场只有 none/fade/slide-up/slide-left/scale-in；驻留 none/drift，主视觉可选 pulse；退场 cut/fade。入场必须在原句时间内落位，不延长歌曲。没有词对齐时使用整句锚点。代码不推测音高、混响尾长或歌词未提供的节奏。

## 导出

`render-remotion.mjs` 使用构建好的合成组件与 @remotion/renderer 输出 H.264 30fps 视频，再由 FFmpeg 合成原曲 AAC。尺寸取用户选定画幅/分辨率；片段使用原歌曲绝对起点。

导出同时一个任务，有进度、取消及错误提示。成片、源方案快照与完成记录保存在歌曲 motion_exports；完成记录和下载在服务重启后保留，运行中任务不自动恢复。

Motion Lab 保留原 pdoom/Three.js 实验渲染；Studio 海报模式暂不执行 pdoom 后处理、三维文字、自适应运动模糊或跨句推挤转场。Remotion 提供组件与逐帧工具，排版与美术效果仍需模板和视觉验证。

接口、版本兼容与提示词见 `motion-director-api.md`。Remotion 商用许可遵循官方说明：https://www.remotion.dev/docs/license/pricing 。Docker/云部署尚未在本机实测。

## 句间交接与竖屏

交接时间属于编译结果，不改 alignment、字词锚点或歌曲长度。短间隔（不超过 0.22 秒）简化为短淡出/直接交接；普通间隔尽量保留海报到下一句，再以不超过 0.36 秒淡出。淡出有足够时间时，primary 比辅文晚 0.10 秒开始退出。超过 1.5 秒的间奏，文字余韵最多延续到句尾后 1.2 秒，之后舞台继续。末句受歌曲长度限制，重叠句在下一句起点交接。没有可用退场时间时直接替换，不抢最后词的演唱。

旧方案明确的 cut 继续直接交接，可在“句间交接”切到 fade 体验分层退出。编译 JSON 保留原 end，并附 handover（mode、visible_end、exit_start、primary_exit_start、next_start）；不是音频尾长估计。

9:16 使用画宽计算字号与间距，长辅文自然折行，主视觉锚点在约 42% 画高，字块限制在约 16%–74% 阅读区域；圆环降低到 24% 不透明度并退到上方边缘。复杂长句仍会缩放以保证安全，不承诺每句固定行数。横屏保持原有字块规则。入场样式库保持独立，未添加遮罩、弹簧或方向性推挤。

## 竖屏主标题折行

主标题不再按默认大字号逐字塞满一行。三至五字优先整行，以实际字体测量求适合字号；六字在字号仍足够时整行，否则比较两行候选，避免末行孤字。六至十二字候选兼顾行长平衡、中文分词边界及已有 emphasis 的完整性；分词只是软约束，不保证理解所有意象。更长标题仍走安全折行与缩放。文字、词组节点与对齐时间不改写，辅文字号继续保持低于主标题的层级；预览、PNG 与 MP4 共用结果。无需重新发送 LLM 提示词，刷新前端即可生效。

## 语义编排

poster.semantic_mode 默认为 auto，off 保留原节点参数。无 relations 时结果保持原样，不自动猜歌词关系。规则按固定优先级执行：空间→对照→引导→否定→重复；唯一 primary、原节点顺序和时间不变，密集快唱的动作降级优先。

- guidance：轻快淡入铺垫、降低辅文权重，原 primary 用缩放落位承接。
- contrast：同类入场、小幅左右错位（画宽 ±1.8%），辅文稍增权重；保留主次层级。
- negation：铺垫降低对比，判断对象使用前景或主视觉强调色；不创建第二个 primary。
- repetition：多个引用块复用入场样式与落位时长比例，仍按各自 alignment 起点进入。
- spatial：多个块有限错位，主视觉驻留微动，不解析 intent 猜上下/三维方向。

单块 repetition/spatial 暂不拆内部子动作，显示“有限支持”。语义提示字号变化限制在 0.8–1.15 倍，最终仍经字体测量、安全区、主辅比与竖屏折行约束。编译 JSON 的 semantic_arrangement 记录实际采用的规则；UI 展示当前实际入场并提供自动/手工切换。源导演数据不被编译器改写。对照不是新增左右两栏模板，空间也不是三维文字。已有方案未含关系时需通过新版 LLM 返回补关系，不能仅切换自动模式就生成语义设计。


中英文显示与换行：导演数据保留原 text，绘制时折叠连续空白并去除汉字间的排版空格；英语和中英交界保留单词间隔。横竖屏纯中文主标题（最多 12 字）比较单行适配或基于分词边界的均衡双行，避免末行孤字；英语按完整单词换行，超宽单词先缩小字号。更长中文块使用通用换行，尚不保证所有标点禁则和语义断句。该规则由共享排版编译器执行，预览、静态海报和 Remotion 导出一致，不改 word_indices 或时间戳。


平行句提示词先选整组的句法焦点策略，再逐句填写现有 nodes。自然主体系列默认主体作为 primary；属性/动作主题可整组选择谓语焦点，例外需写出具体依据。共享版式、色彩角色和动作语法，不共享歌词索引或像素数值。单句输入提供前后各两句的文字、段落与已保存 poster_context（不含字词索引或绝对时间），便于跨过解释句继承设计。主歌默认静置、无拍点回弹。这是 LLM 创作约束，不是自动识别平行句的编译器；已保存方案不会自动重写。

视觉强度统一规则：`poster.visual_intensity` 支持 auto（默认）、restrained（克制）、expanded（展开）、peak（峰值），界面“逐句调整”可覆盖。自动按已有 section 判定主歌/桥段/尾奏为克制、副歌为展开，无标签为展开；不猜测高潮，峰值由导演明确选择。字号倍率 0.82/1/1.12，入场幅度倍率 0.65/1/1.12；折行与安全区优先，密集歌词峰值降为展开且继续禁用位移与驻留响应。档位不修改角色、颜色或对齐时间，旧方案默认 auto 不改变旧 cue 签名。

驻留 drift 改为每秒 0.9 弧度的慢速正弦，基础幅度为短边的 0.06%，再按档位缩放，开始的 0.6 秒渐入。720 短边展开档最大位移 0.432px（旧横屏 1.44px、旧竖屏 2.56px）。Canvas 与 Remotion 共用 `posterHoldState`，不使用墙钟或随机数；beat pulse 仍是独立声音响应，快唱继续关闭。

自动 Gemini 导演：后端 `src/motion_llm.py` 使用 Gemini 原生 GenerateContent REST 接口，默认模型 `gemini-3.8-flash`，可用 `M2V_LLM_MODEL` 指定其他可用 Gemini 型号。在本分支根目录 `.env` 设置 `GEMINI_API_KEY`（环境变量优先；密钥不返回浏览器、不进入日志、不提交 Git）。其余配置见 `.env.example`。输入只有现有导演提示词的歌词、对齐与分析数据，不上传音频文件。

页面提供“Gemini 导演当前句／整曲”，与“规则生成基础方案”区别明确。后台任务依次运行生成、校验，JSON/歌词/结构校验失败最多重新生成一次，认证/超时不自动重试，限流按下方备用规则处理。生成失败不保存、不会回退成规则方案。校验成功后点击“应用 Gemini 方案并保存”，才更新预览和导出。服务器比较生成前后完整工程和方案快照，生成期间任何修改会导致 409，前端也阻止覆盖未保存的修改。单句只替换目标、整曲保护锁定条目。任务最多保留最近 20 个在内存中，服务重启后任务失效。

接口：`GET /api/motion/director/config` 只返回配置状态与模型名；`POST /director/generate` 参数沿用 project_id/style/instruction 与可选 line_id，返回 202 与任务 id；`GET /director/jobs/{id}` 返回进度及校验后的草案；`POST /director/jobs/{id}/apply` 应用并保存。最多一个生成任务同时运行。连接超时 15 秒，单次生成默认 180 秒，输出上限默认 16384 tokens；整曲截断时建议增大上限或使用单句。

官方资料：[模型列表](https://ai.google.dev/gemini-api/docs/models)、[JSON 输出](https://ai.google.dev/gemini-api/docs/structured-output)。

模型额度备用规则：默认主模型 `gemini-3.8-flash`，备用 `gemini-3.5-flash-lite`（`M2V_LLM_FALLBACK_MODEL` 可覆盖，空值关闭）。主模型返回 HTTP 429（限流／额度不足）时同一任务最多切换一次，仍使用原提示词、密钥与完整校验；后续 JSON 修正继续使用备用模型。认证、网络、超时、内容过滤、格式错误与输出截断不会触发切换。备用也返回 429 时明确失败，保留原方案，不继续轮询模型。每个新任务重新优先尝试主模型，不持久改写用户配置。任务返回 requested_model/model/fallback_used，页面展示实际模型。共用账户额度或预付余额不足不保证能靠换模型解决。

驻留呼吸暂时下线：所有画幅的编译节点 hold 固定 none，共用驻留计算始终返回 drift=0；旧缓存节点也不执行呼吸位移。空间关系不再注入 drift，页面移除呼吸选择，新导演提示词和未锁定节点 schema 仅允许 hold=none。存储模型继续接受旧 drift 字段以保留锁定条目和签名，但播放、海报预览及 MP4 均保持静置。入场、句间交接和独立拍点 pulse 不受影响。此规则取代此前弱化呼吸的描述。
