# Fovea MV Chrome 插件（1.5.3）

界面使用英文。Suno 悬浮栏从左至右为歌曲名称、Download MP3、Create MP4 与视频片段选择；歌曲名称仅作展示。长歌名自动省略，悬停可查看完整名称。MP4 的片段选择不影响整曲 MP3 下载。

## 功能

每次新下载 MP3 或创建 MP4，都会针对当前歌曲要求确认已 Publish、拥有版权或合法授权、下载渠道与额度获准、使用目的合法。取消不发起下载或生成任务。确认不长期记忆，不代表程序验证了版权，也不能替代 Suno 授权。本次仅新增声明与提示，既有音频获取路径仍需另行整改或获得授权，不能据此宣称合规。

最小化悬浮栏会同时隐藏进度提示框；后台任务继续执行，展开后显示最新且未过期的状态。隐藏悬浮栏也会隐藏提示框。

- 在 Suno 页面识别歌曲名称、作者、封面、歌词和公开状态。
- 页面悬浮按钮可选择副歌 30 秒、第一段主歌 30 秒、前奏 30 秒或完整歌曲。
- 调用已配置的本地或云端服务生成 9:16 歌词视频，并启动 MP4 下载。
- 插件弹窗提供「下载原曲 MP3」：直接下载当前歌曲音频，不调用对齐或渲染服务。

## 安装或更新

插件重新加载会使已打开页面中的旧脚本失效。1.5.1 会停止旧页面的轮询与路由监听、移除旧按钮，并提示刷新 Suno；必须刷新页面才能连接新版插件。Chrome 扩展错误页的历史记录可清除。

1. 打开 Chrome 的 `chrome://extensions/`，开启「开发者模式」。
2. 首次安装选择「加载已解压的扩展程序」，选中本目录；更新已有插件时点击其「重新加载」。若原插件来自其他目录，请改为加载本目录。
3. 刷新 Suno 标签页，并播放目标歌曲，让插件识别最新歌曲数据。
4. 点击浏览器工具栏的 Fovea MV 图标，再点击「下载原曲 MP3」。进度与结果以 Chrome 下载列表为准。

MP3 默认保存到浏览器下载目录，重名文件自动增加序号。该入口下载整首原曲，不使用视频的 30 秒片段选择。

## 下载范围与提示

MP3 和 MP4 均要求歌曲已 Publish。明确未发布时直接提示在 Suno 的 (…) 菜单发布后重试；未知状态不显示“已发布”，MP3 会调用新版后台 `/api/suno/publish_status` 核实。网络故障与未发布分开提示。

插件优先使用该歌曲的 API 音频地址，其次使用歌曲 ID 匹配的播放器地址，不使用没有歌曲归属的历史 Blob。直接下载前检查 MP3 文件头；视频、AAC 或网页错误响应不会被直接改名成 `.mp3`。

没有 MP3 地址、CDN 返回 403/404 或源格式不是 MP3 时，只要识别到了歌曲编号，插件会调用所选后台已有的 `/api/suno/download_mp3` 接口。后台下载原曲，必要时从 MP4 提取音轨并转换为 MP3，不运行人声分离、歌词对齐或视频渲染。已确认公开且直链有效时无需后台；状态核实和兜底下载需要新版后台可用。

后台兜底通过 Chrome 下载管理器发起；弹窗关闭后下载仍可继续。按钮提示“开始下载”不代表文件已完成，请在 Chrome 下载列表查看结果；后台故障或网络中断可能导致下载失败。

## 开发检查

在仓库根目录执行：

```sh
node --test chrome_extension/tests/*.test.cjs
```

检查包含 MP3 格式判断、错误响应、文件名清理、下载错误处理，以及歌曲切换后媒体来源的匹配。自动检查使用模拟浏览器接口，真实 Suno 页面下载需另行验证。

### 长任务与网络中断（1.4.2）

视频接口先返回任务编号，下载、分离、对齐及渲染在后台排队执行。页面进度来自后台实际状态，不再根据等待秒数猜测。插件逐次查询任务，临时网络错误或 HTTP 429/502/503/504 会自动重试；连续等待超过 20 分钟只停止本轮查询，不取消后台任务。

任务列表保存在插件本地，支持多首歌。关闭页面或查询中断后，在弹窗选择任务并点击 Resume selected video。浏览器后台定时检查已提交任务，完成后启动下载。重复点击同一未完成的歌曲片段，会恢复已有任务；提交响应丢失后的重试使用同一个请求编号，配合新版后台避免重复渲染。

新版后台将任务状态写入 `work/video_tasks/`，记录保留七天。服务器重启后，已完成任务可继续查询和下载；未完成任务明确标为 interrupted，不会自动重跑。用户需要重新生成时才创建新任务。部署磁盘被重置仍会丢失记录和文件；本实现面向单进程服务，不是分布式任务队列。

MP4 按点击时识别到的歌曲 ID 获取音频，不使用无法确认归属的历史 Blob。MP3/MP4 会跟踪 Chrome 的实际下载状态，失败时可在弹窗 Retry download。恢复已有下载不会重新渲染视频。

默认权限限于 Suno、Suno 媒体、本地服务和官方后台。自定义 HTTPS 服务器及额外 CDN 域名单独请求授权。云端地址不允许 HTTP、内嵌账号密码或路径。修改服务器后 Suno 悬浮栏同步生效。

首次发送数据前会说明传输内容；隐私详情见插件内 Privacy & data handling，以及后台公开页面 `/privacy/extension`。项目文件并未自动过期删除，不能将清除本地历史误解为删除云端音频或视频。悬浮栏支持收起；弹窗可隐藏或恢复它。Clear finished history 只移除已结束的本地记录，保留进行中的任务，不取消服务器任务。


**仅下载 MP3 入口**：Suno 页面右下方悬浮栏的“🎵 仅下载 MP3”，或 Chrome 工具栏 Fovea MV 插件弹窗中的同名按钮。旧插件不会自动刷新代码：在 `chrome://extensions` 重新加载本目录，再刷新 Suno 页面。下载整首当前歌曲，不受视频片段选择影响。


1.4.4 复用网站已有的“仅下载”接口 `/api/suno/download_mp3`，无需提交新的音频导出任务或等待插件轮询。旧版 `/api/plugin/export_audio` 接口保留，兼容已有客户端。
