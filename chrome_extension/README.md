# Fovea MV Chrome 插件（1.4.1）

## 功能

- 在 Suno 页面识别歌曲名称、作者、封面、歌词和公开状态。
- 页面悬浮按钮可选择副歌 30 秒、第一段主歌 30 秒、前奏 30 秒或完整歌曲。
- 调用已配置的本地或云端服务生成 9:16 歌词视频，并启动 MP4 下载。
- 插件弹窗提供「下载原曲 MP3」：直接下载当前歌曲音频，不调用对齐或渲染服务。

## 安装或更新

1. 打开 Chrome 的 `chrome://extensions/`，开启「开发者模式」。
2. 首次安装选择「加载已解压的扩展程序」，选中本目录；更新已有插件时点击其「重新加载」。若原插件来自其他目录，请改为加载本目录。
3. 刷新 Suno 标签页，并播放目标歌曲，让插件识别最新歌曲数据。
4. 点击浏览器工具栏的 Fovea MV 图标，再点击「下载原曲 MP3」。进度与结果以 Chrome 下载列表为准。

MP3 默认保存到浏览器下载目录，重名文件自动增加序号。该入口下载整首原曲，不使用视频的 30 秒片段选择。

## 下载范围与提示

页面需要提供可访问的 HTTPS MP3 地址。插件优先使用该歌曲的 API 音频地址，其次使用歌曲 ID 匹配的播放器地址，不使用没有歌曲归属的历史 Blob。下载前检查 MP3 文件头；视频、AAC 或网页错误响应不会被直接改名成 `.mp3`。

如果未识别到音频地址，请刷新页面并播放目标歌曲。CDN 拒绝访问、源格式不是 MP3或地址失效时会显示错误；本功能不进行格式转码。MP4 生成仍沿用原有公开状态检查与后台服务。

## 开发检查

在仓库根目录执行：

```sh
node --test chrome_extension/tests/*.test.cjs
```

检查包含 MP3 格式判断、错误响应、文件名清理、下载错误处理，以及歌曲切换后媒体来源的匹配。自动检查使用模拟浏览器接口，真实 Suno 页面下载需另行验证。

### 长任务与网络中断（1.4.2）

视频接口先返回任务编号，下载、分离、对齐及渲染在后台排队执行。页面进度来自后台实际状态，不再根据等待秒数猜测。插件逐次查询任务，临时网络错误或 HTTP 429/502/503/504 会自动重试；连续等待超过 20 分钟只停止本轮查询，不取消后台任务。

提交成功后的最近一个任务编号会保存在插件本地。关闭页面或查询中断后，打开插件点击“继续查询上次任务”，查询同一任务并在完成后下载，不会重新生成。生成新任务前建议先查询旧任务。重新加载插件后请刷新 Suno 页面，使进度提示使用最新版本。

目前任务状态保存在后端进程内：后台重启会丢失查询记录，插件会明确提示任务不存在；已输出的文件是否保留取决于部署磁盘。此机制解决长 HTTP 请求和临时断网，不提供跨服务器重启的任务恢复。后续可用持久化任务队列完善。


**仅下载 MP3 入口**：Suno 页面右下方悬浮栏的“🎵 仅下载 MP3”，或 Chrome 工具栏 Fovea MV 插件弹窗中的同名按钮。旧插件不会自动刷新代码：在 `chrome://extensions` 重新加载本目录，再刷新 Suno 页面。MP3 按钮读取当前选中的歌曲，优先直接下载原 MP3；若缺失、返回 403/404 或实际为 MP4，使用所选后台的音频下载接口，复用 `download_song()` 的 MP4 音轨提取能力。此兜底需要新版后台且歌曲可访问，不运行人声分离、歌词对齐或视频渲染。


1.4.3 补充 MP4 音轨兜底：仅下载 MP3 并不需要 Demucs。已有 MP3 直接交付，不重复有损编码；其他可解码音频才转换为 MP3。后台接口为 `/api/plugin/export_audio`，仍采用任务编号加进度查询，避免长请求占用网关。
