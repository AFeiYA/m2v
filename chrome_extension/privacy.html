Privacy & data handling

Updated: October 9, 2026. Applies to Fovea MV Chrome extension 1.5.4.

Rights & publication notice

Before each new MP3 download or MP4 creation, you must confirm that the selected song is published, that you own the rights or have authorization to use its audio, lyrics and cover, and that your download and intended use are allowed by Suno’s terms and your plan. Cancel to stop. Public playback or Publish status does not establish ownership, download entitlement or commercial rights.

This is a user declaration, not verification of rights. It does not override platform terms or authorize bypassing payment, download quotas or content protections. Fovea MV is independent of Suno and is not endorsed by it. Existing audio retrieval paths have not been changed by this notice; the notice alone does not establish their compliance.

What happens when you use it

The extension reads song metadata and media addresses on Suno pages. It does not request access to cookies, passwords, browser history or social publishing accounts. It has no analytics or advertising trackers.

Download MP3: an available MP3 downloads directly from Suno’s media service. The selected server may receive the song link to verify publication; if the MP3 is unavailable, it downloads/extracts the audio. Both MP3 and MP4 require a publicly published song. Unknown publication status is checked rather than assumed public.

Create MP4: the selected server receives the song ID, title, artist, lyrics/prompt, cover address and chosen clip. It downloads the audio, aligns lyrics and renders video. Its hosting and processing infrastructure handles this data. This quick-export feature does not call the AI Director’s LLM API.

Where data stays

Chrome stores server preferences, consent choices, task identifiers, song metadata for recovery, and recent download statuses locally. Downloaded files stay in your Chrome download folder. Clear finished history in the popup to remove finished task and download records; active jobs are kept. This does not delete files or cancel server jobs. Uninstalling removes extension storage.

The backend task recovery window is seven days. Expired journals are removed on lookup or when new video jobs trigger cleanup; this cleanup is lazy, so idle servers may keep expired files longer. Audio, lyrics, covers, alignment files and rendered videos are stored on the selected server; this release does not automatically delete those project files. A local server keeps them on your computer. A cloud server keeps them on its host. Contact the operator to request deletion; do not upload material you cannot share with that operator.

Server restarts can interrupt unfinished work. Recovery of completed results requires the server disk to survive the restart. Temporary cloud disks may lose files.

Permissions and control

Suno and media-host access detects and downloads songs. Downloads permission saves files and checks completion. Storage remembers settings and jobs. Alarms checks existing jobs after the background worker sleeps. Access to a custom HTTPS server is requested only when you save its address. Cloud communication uses HTTPS; local loopback servers may use HTTP.

Use your own music or music you have permission to process. Fovea MV is an independent tool, not an official Suno product.

Support and deletion requests: project support. Do not post private audio, credentials, task IDs or download links in public issues; ask for a private support channel first.
